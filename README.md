# 📐 Geometric Calculator

Calculadora de áreas de formas geométricas desenvolvida em duas linguagens: **Portugol** e **Python**.

## 📋 Descrição

Este projeto calcula a área de quatro formas geométricas a partir de dados inseridos pelo usuário. Foi desenvolvido originalmente em **Portugol Studio** como exercício de lógica de programação e posteriormente reescrito em **Python**.

## 🔷 Formas Suportadas

| # | Forma | Fórmula |
|---|-------|---------|
| 1 | Triângulo | `(base × altura) / 2` |
| 2 | Retângulo | `base × altura` |
| 3 | Círculo | `π × raio²` |
| 4 | Quadrado | `lado²` |

## 🚀 Como Executar

### Portugol
1. Instale o [Portugol Studio](https://portugol.dev/)
2. Abra o arquivo `portugol/geometric_calculator.por`
3. Clique em **Executar**

### Python
1. Certifique-se de ter o [Python 3](https://www.python.org/) instalado
2. No terminal, navegue até a pasta `python/`
3. Execute o comando:
```bash
python geometric_calculator.py
```
